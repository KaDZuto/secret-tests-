## Лицензия

Проект распространяется на условиях MIT. Все ассеты в game/absorbed/ — third_party=true, redistributable=false. Не удаляй и не изменяй лицензионные заголовки. Если добавляешь новый код — он под MIT.

ВАЖНО: game/vendor/unrpa/ — GPL-3.0. При распространении дистрибутива GPL-3.0 действует на весь дистрибутив. Не удаляй vendored unrpa без необходимости — он нужен для чтения .rpa архивов. Если работаешь с лицензиями — учитывай это противоречие.

## Экономия токенов

1. НЕ перечитывай файлы, которые уже прочитал — используй общую память (agent_bus/STATE.json)
2. НЕ генерируй длинные промпты — используй существующие шаблоны в agent_bus/
3. Перед каждым действием проверяй agent_bus/QUEUE.jsonl — возможно, задача уже сделана
4. Пиши краткие коммиты в agent_bus/bus.jsonl после каждого значимого шага

## Приоритеты

### Критические баги (быстрые исправления)

1. Удалить game/zz_ogurec.rpy (отладочный файл, вызывает краш)
2. Исправить config.gamedir → store.config.gamedir в engine.py:1273 (и проверить другие места: cannibalism.py, layered_sprite.py, music.py, sprite_fit.py, demo.rpy)
3. Исправить ошибку стиля border в vn_styles.rpy:241 (свойство удалено в Ren'Py 8)
4. Исправить баг с описанием при создании игры (описание теряется при fallback на random_world())

### Сложные задачи (для Opus)

5. Исправить состояние гонки на _PENDING_VOICE в engine.py:1109 (нужна аккуратная блокировка)
6. Написать загрузчик внешних глав (JSON-формат, интеграция с story_chapter.py)
7. Добавить проверку смысла текста (независимая валидация качества)
8. Добавить настройки персонажей по отдельности (TTS, позиция, масштаб)
9. Подключить fit_window() для адаптивного размера окна
10. Запечь оставшихся 8 персонажей SAO (измерить смещения, запечь, проверить)

### Критерии готовности

- Пункт 1: файл удалён, игра запускается без краша
- Пункт 2: все обращения к config.gamedir исправлены, загрузка из буфера работает
- Пункт 3: стиль работает, нет ошибок в логе
- Пункт 4: описание попадает в мир при создании игры
- Пункт 5: нет потери аудио при медленном TTS
- Пункт 6: глава загружается из JSON и играется
- Пункт 7: качество текста проверяется независимо
- Пункт 8: настройки персонажа сохраняются и применяются
- Пункт 9: окно адаптируется к разрешению
- Пункт 10: 8 персонажей запечены и отображаются
