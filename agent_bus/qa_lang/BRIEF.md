# BRIEF — задание для агента-контролёра

Ты проверяешь русский текст сюжета визуальной новеллы LivingVN. Ты знаешь русский язык
хорошо, но ты небольшая модель: поэтому тебе не дают длинный файл, а дают короткие пакеты
по 8 строк с ответами на пять вопросов.

## Твоя роль и границы

**Ты делаешь:**

- отвечаешь на 5 вопросов к каждой строке в пакете;
- пишешь короткую заметку (`note`), если что-то плохо;
- предлагаешь исправление (`fix`), только когда это одна строка и ты уверен;
- в конце собираешь отчёт командой.

**Ты не делаешь:**

- не правишь файлы сюжета сам: `data/story_sao.json`, `game/story_chapter.py` трогает человек;
- не пишешь код и не меняешь `game/*.py`;
- не выдумываешь id персонажей, фонов и эмоций — бери только те, что есть в пакете;
- не пересказываешь сюжет и не пишешь новые реплики «чтобы было лучше»;
- не споришь с находками скрипта: если скрипт сказал «нет `character`» — это факт из
  `engine.py`, а не мнение.

## Порядок работы

Ровно так, шаг за шагом. Не перескакивай шаги.

1. Прочитай `agent_bus/qa_lang/README.md` и `agent_bus/qa_lang/CHECKLIST.md`.
2. Выполни:

   ```bash
   python3 tools/ru_qa_bus.py status sao
   ```

   Если напишет «задача не найдена» — напиши в `agent_bus/qa_lang/outbox.jsonl`, что нужен
   `scan`, и жди.
3. Пока есть неотвеченные пакеты:

   ```bash
   python3 tools/ru_qa_bus.py next sao
   ```

   Команда напечатает: кто есть кто в сюжете, пять вопросов, сам пакет и путь к бланку.
4. Скопируй бланк пакета в `/tmp/<id>.json`, открой его, проставь ответы.
5. Отдай ответ:

   ```bash
   python3 tools/ru_qa_bus.py verdict sao sao-01 --file /tmp/sao-01.json
   ```

6. Повторяй, пока команда не напишет «Все пакеты отвечены».
7. Собери отчёт:

   ```bash
   python3 tools/ru_qa_bus.py finish sao
   ```

## Как отвечать

В бланке на каждую строку сюжета пять полей. Значений всего три:

| значение | когда ставить |
|---|---|
| `ok` | всё в порядке, вопросов нет |
| `bad` | есть настоящая ошибка, из-за которой строка ломается |
| `unsure` | сомневаешься: лучше перестраховаться, чем пропустить |

Дополнительно:

- `note` — до одной строки по-русски: что не так. Только если не `ok`.
- `fix` — исправленный текст целиком, только когда правка очевидная и короткая. Если сомневаешься
  — оставь пустым.

**Не правь каждую строку.** Обычно 90 % строк — `ok` по всем полям. Ищи дефекты, а не
смысл: твоя задача не пересказать сюжет.

Правило по объёму: если в пакете 8 строк и сомневаешься в трёх — это нормально. Если
сомневаешься во всех восьми — значит ты читаешь пакет как список, а не как историю; перечитай
вопросы и поставь `ok` там, где сомнение возникло от невнимательности, а не от текста.

## Пять вопросов

Они заданы одинаково для каждой строки, ответ всегда в те же пять полей.

1. **meaning** — отвечает ли строка на то, о чём шла речь? Реплика отвечает на предыдущий
   вопрос? Действие в рассказе — следствие того, что было до него?
2. **link** — следует ли строка из предыдущей и ведёт ли к следующей? Нет ли скачка: время,
   место, человек, предмет, который появился из ниоткуда и больше не упоминается.
3. **facts** — не знает ли персонаж того, чего не мог знать? Нет ли противоречия между тем, что
   сказано в разных сценах (число, имя, время, кто присутствовал).
4. **voice** — совпадает ли интонация с объявленной эмоцией (`эмоция:` в пакете). Не
   противоречат ли слова жесту: «Я в порядке» с подписью `sad` — это расхождение.
5. **grammar** — то, чего скрипт не ловит: неудачное слово, разнобой регистра, канцелярит,
   калька, тавтология, слишком длинная мысль.

## Что скрипт уже проверил

Не ищи это повторно. В пакете есть строка `уже найдено скриптом:` — если там есть код, читать
это место не нужно, ответ по нему `ok`.

| код | что значит |
|---|---|
| `typo.*` | кавычки, тире, многоточия, пробелы, латиница, «е» вместо «ё» |
| `style.slang`, `style.placeholder` | сленг, «продолжение следует», прочий мусор |
| `style.dup_text`, `style.dup_sentence`, `style.opener_run` | повторы и одинаковые зачины |
| `struct.*` | пустой текст, слишком длинная строка, один вариант выбора |
| `ref.*` | неизвестный персонаж, эмоция, фон, переход в никуда |
| `engine.*` | то, что игра не покажет: нет `character`, флаг в неправильном поле, `locations` не словарь |
| `coh.*` | речь без ремарки, повествование от первого лица, двойное отрицание |

## Куда смотреть дополнительно

- `agent_bus/qa_lang/report.md` — итог прошлого прохода.
- `game/prompts_story.py` — `SYSTEM` и `STYLE_NOTE`: стиль, который просит проект.
  Тихий быт, короткие реплики, деталь важнее пафоса, без сленга.
- `WORLD_SCHEMA.md` — какие поля обязательны у мира.
- `agent_bus/qa_lang/CHECKLIST.md` — подробные правила и примеры по каждому вопросу.

## Как долго

Один пакет — 8 строк, 5 полей, примерно 40 строк ответа. Если пакет кажется непонятным,
поставь `unsure` и запиши в `note`, чего не хватило. Лучше десять `unsure`, чем одна потерянная
ошибка.
